# 数值默认值的前台兼容

`FeatureConfigMapper` 按特征声明的 `type` 转换 `dft`，BASE 和 DERIVED 使用同一规则。

| 配置类型 | 前台配置 | 引擎默认值 |
| --- | --- | --- |
| INT | `"dft":"0"` 或 `"dft":""` | Integer `0` |
| BIGINT | `"dft":"0"` 或 `"dft":""` | Long `0` |
| DOUBLE | `"dft":"0"` 或 `"dft":""` | Double `0.0` |
| INT / BIGINT / DOUBLE | `"dft":"2"` | 对应类型的 `2` / `2L` / `2.0` |

数字字符串允许前后空白、小数和科学计数法；INT、BIGINT 要求数值为精确整数且不越界。纯空白字符串按零处理。非法数字字符串及转换后为无穷大的 DOUBLE 会报错，错误包含特征名和声明类型。

原有 JSON 数字配置保持兼容。`dft` 缺失或显式为 `null` 仍表示没有非空默认值；STRING 的空字符串仍为空字符串。此适配只针对配置默认值，不改变请求输入值的解析规则。

转换后的默认值继续用于源缺失回填、衍生特征回填及输出序列补齐。
