# Configuring Feature DAG Models

Gather evidence in stages before making a validation or configuration claim. Never invent missing feature semantics.

- Read [expression grammar](references/expression-grammar.md) when checking expression syntax or extracting feature references.
- Read [feature fields](references/feature-fields.md) when completing or comparing BASE and DERIVED metadata.
- Read [output contracts](references/output-contracts.md) when returning property additions or a final model feature-set JSON.
- Read [validator extension](references/validator-extension.md) when a compatible remote validator is available or its fallback must be disclosed.
- Read [operator contracts](references/operator-contracts.md) after syntax succeeds and semantic inference is needed.
